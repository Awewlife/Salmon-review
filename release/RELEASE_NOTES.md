# Salmon Review v0.3.10

主程序与更新组件现在可以通过网页一起更新。更新前校验镜像并备份数据；两个组件全部通过检查后完成，失败恢复旧版，中断后根据本机日志恢复。

## 这次需要完整安装包过渡一次

0.3.9 及更早组件不具备自更新能力，请下载 `SalmonReview-v0.3.10-windows-x64.zip`，完整解压后使用新版 `Start.cmd`，沿用原 Compose 项目名和数据卷。例如原项目为 `salmon-review-dev`：

```powershell
.\Start.cmd -ProjectName salmon-review-dev
```

请保留本版启动器。以后的兼容更新可在「数据与同步 → 版本与更新」中完成，包括更新组件自身。无需重新授权已有 GitHub 凭据；凭据本身失效时需重新连接。

下载阶段可取消；进入交接和安装阶段请等待完成，网页会自动重连。不要删除数据卷。未知协议或不兼容数据迁移仍可能需要完整包。

附件包括完整 Windows 包、对应源码和第三方许可材料；签名网页更新清单使用协议 2，旧组件将提示使用完整包。
