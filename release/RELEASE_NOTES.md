# Salmon Review v0.3.3

本次更新改善趋势分享、记录完整性判断和同步体验。适用于 **Windows Intel/AMD 64 位电脑 + Docker Desktop 的 Linux 容器模式**。

## 这版有什么变化？

- **选一段场次导出图片**：在“查看详细趋势 → 场次筛选与导出”中选起止场次，导出单张或全部三张图，支持 PNG / SVG，并保留坐标轴和队友选择。
- **更清楚的趋势详情**：保留搬蛋、击杀、被救援三张同步滚动的图，移除三合一；导出选项默认折叠，入口改为“查看详细趋势”。
- **中断记录单独计数**：普通结算全部保存时正确显示完整；额外的中断记录另行说明，不参与统计，仍会阻断跨缺口的连续同队推断。
- **读取时保留战绩**：状态与新数据在后台读取，失败也不清空已展示内容；同标签页刷新先显示上次成功读取的快照，没有新变化不重绘。
- **手动重试只等 5 秒**：普通网络失败后的手动等待与自动退避分开；明确限流时两者都遵守等待时间。
- **登录失效可直接重新连接**：连接成功解除普通等待，仍有限流时保留限流期限。

## 普通玩家下载哪个文件？

下载 **`SalmonReview-v0.3.3-windows-x64.zip`**，全部解压，打开 Docker Desktop，双击 **`Start.cmd`**。安装器校验并导入预构建镜像，无需安装 Node.js、Python，也不需要自行构建。

其他附件：

- `SalmonReview-v0.3.3-source.zip`：与镜像对应的项目源码。
- `SalmonReview-v0.3.3-third-party.zip`：第三方声明、nxapi 对应源码及组件清单。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。

GitHub 自动提供的 “Source code” 压缩包没有预构建镜像。安装不访问 Docker Hub / npm；登录、同步和首次图片加载仍需联网。ARM 电脑不在本安装包支持范围。

## 从 v0.3.2 升级，自动沿用数据

1. 建议先在网页下载一份战绩备份作为保险，正常升级不需要重新导入。
2. 下载新版 windows-x64.zip，解压到新文件夹；复制旧 `.env`（如果有）。
3. 默认项目名用户双击新版 `Start.cmd`。使用自定义项目名时运行 `./Start.cmd -ProjectName 原项目名`，自定义端口继续沿用原设置。
4. 脚本替换程序容器，继续使用同名数据卷；战绩和登录缓存保留。完成后刷新网页。

不要删除 Docker 数据卷，也不要执行 `docker compose down -v`。安装包不包含维护者的账号、战绩、登录缓存或数据卷。登录凭据本身若已过期，仍需按页面提示重新连接。

## 验证与版本边界

46 项自动化测试通过，已验证趋势范围、缺场/中断处理、后台读取保留、5 秒重试、限流及模拟过期重连。模拟验证不等同于其他玩家全新电脑安装或真实凭据自然过期后的验收。

这是私有仓库的预发布版，只有获授权访问仓库的人可以下载。没有 AI 分析，不适用于公网多人服务。外部浏览器导出文件保存到下载目录等人工验收仍见 `VALIDATION.md` 和 `BETA_TESTING.md`。

项目采用 AGPL-3.0-or-later；第三方授权和声明缺口继续按 `THIRD_PARTY_NOTICES.md` 披露。本次更新不改变仓库可见性，也不表示这些缺口已经解决。
