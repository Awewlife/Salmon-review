# Salmon Review v0.3.12（私有试用版）

公开准备前的最后一版私有发行包。仓库继续保持私有。

## 本版变化

- 用本地维护的 SplatNet 常量兼容模块替换 `splatnet3-types`，保留 nxapi 的登录、会话刷新和打工同步；补充常量来源记录及回归测试。
- 补齐 `tr46 0.0.3` 的 Sebastian Mayr 版权声明和完整 MIT 许可，固定上游来源与文件哈希。依赖校验、镜像构建和发行打包会检查材料是否完整匹配。
- 调整队员名片布局、昵称尺寸和徽章位置；长昵称自动适应宽度，并提供带 OFL 许可的本地字体回退。

## 安装与升级

- **已使用 0.3.10 或更新完整包启动的用户**：在“数据与同步 → 版本与更新”中检查并安装本版，主程序和更新组件一并升级。
- **0.3.9 及更早版本，或首次安装**：下载 `SalmonReview-v0.3.12-windows-x64.zip`，完整解压后运行 `Start.cmd`。沿用原 Compose 项目名和数据卷；自定义项目可运行 `Start.cmd -ProjectName 原项目名`。
- 不要删除原数据卷，无需导出再导入已有战绩。下载阶段可取消；安装开始后等待网页自动重连。

本版包含 Windows 完整安装包、对应源码、第三方材料和签名网页更新文件。旧 Release 附件不随本版更改；公开仓库更新适配及完整镜像分发材料核对仍待后续完成。本版不表示仓库已具备公开发行条件。
