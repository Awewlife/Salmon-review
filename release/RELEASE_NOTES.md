# Salmon Review v0.3.11（私有试用版）

本版汇总当前功能改动，仓库继续保持私有。

## 本版变化

- 队员名片与工服：点击对局详情中的队员名称，查看该场保存的名片、称号、编号、徽章、工服和武器。采用接近官方的布局，图片首次查看时下载并缓存，失败可重试。
- 本期击杀详情：在场均击杀卡片点击“击杀详情”，按场次范围查看个人击杀数、巨大鲑鱼出现总数、占比和分类明细。怪物名称配图，支持导出完整高清 PNG；掉线及必要字段缺失的场次不计入统计。
- 可选红蛋趋势：在趋势详情的“更多图表”中开启，支持数量／占比、团队合计、25% 参考线、同步定位和显示偏好记忆。
- 自定义趋势导出：四张图表可任意选择，并通过拖动或键盘调整导出顺序；支持 PNG／SVG，浏览器记住选择和顺序。
- 重写安装说明，明确 Docker Desktop 的 Linux 容器模式及 WSL 2 设置。

## 安装与升级

- **已使用 0.3.10 完整包启动的用户**：可在“数据与同步 → 版本与更新”中检查并安装本版，主程序和更新组件一并升级。
- **0.3.9 及更早版本，或首次安装**：下载 `SalmonReview-v0.3.11-windows-x64.zip`，完整解压后运行 `Start.cmd`。升级时沿用原 Compose 项目名和数据卷；自定义项目可运行 `Start.cmd -ProjectName 原项目名`。
- 请保留 0.3.10 或更新版本的启动器。不要删除原数据卷，无需导出再导入已有战绩。
- 下载阶段可取消；开始安装后请等待完成，网页会自动重连。

附件包含 Windows 完整安装包、对应源码、第三方材料和签名网页更新文件。仍为私有开发预览；上游许可材料缺口及外部机器验收情况见 `BETA_TESTING.md`。
