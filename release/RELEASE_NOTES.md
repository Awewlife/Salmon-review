# Salmon Review v0.4.0

首个公开发行候选版本。提供 Windows x64 安装包，以及 Intel Mac 和 M 系列 Mac 测试安装包，通过 Docker Desktop 的对应架构 Linux 容器运行。本草稿待维护者确认后发布。

> **Mac 安装包尚未经过实机测试。** Intel Mac 和 M 系列 Mac 均未在真实 Mac 上完成安装验收。目前仅完成脚本与 Linux 容器验证（ARM64 使用模拟运行）；macOS 上的实际安装、登录同步及图表导出仍待验证。

## 本版变化

- 新增 Mac 启动器及 Intel / M 系列分别使用的 amd64 / arm64 镜像；网页更新按架构选择并校验附件。保留原 Windows 安装包名称和启动流程。
- 新增官方打工生涯纪录和 NSO 头像，查看巨大鲑鱼／头目累计击倒数及各地图最高段位分数。
- 新增五维图与范围选择；单场详情也可查看，导出包含图例、数据表和场次范围。
- 新增简繁中文、英文、日文及鱿鱼语切换，覆盖弹窗、图表提示和导出；名牌称号使用专用语言表。
- 鱿鱼语仅导出 PNG，不下载嵌入字体文件的 SVG；补齐字体与 Lean 数据署名、来源及权利边界说明。
- 改善趋势提示框避让、长文本布局与数据库展示缓存；安装包补齐 README 图片和引用文档，包含子目录文件校验。
- README 使用四张实际界面截图紧凑展示，P4 为数量对比；玩家 ID 已匿名，保留原始曲线和数值。

- 公开发行版无需 GitHub 令牌即可检查和下载更新；私有测试或 API 限流时，可使用自己的可选凭据。
- 为最终镜像提供版本及哈希匹配的应用、nxapi、Node、原生库和 Debian 源码与构建说明，打包时强制检查。
- 更新系统安全补丁；运行镜像移除构建工具和其他平台的二进制附件。
- 保留已有战绩、登录状态和数据卷。四张趋势图可任意选择、拖动排序后导出。

## 安装与迁移

1. 下载 `SalmonReview-v0.4.0-windows-x64.zip`，完整解压后运行 `Start.cmd`。
2. 使用 Docker Desktop 的 Linux 容器模式，通常保持默认即可。WSL 缺失或版本过低时按提示安装或更新，无需另装 Ubuntu。
3. **旧私有版用户也须用本版完整包启动一次**：沿用原 Compose 项目名和数据卷。自定义项目使用 `Start.cmd -ProjectName 原项目名`。不要删除原数据卷。
4. 完成迁移后，主程序与更新组件均支持网页匿名更新。下载阶段可取消；安装后等待网页重连。

Mac 用户下载 `macos-x64`（Intel）或 `macos-arm64`（M 系列）ZIP，完整解压后运行 `Start.command`。自定义项目使用 `bash Start.command --project-name 原项目名`。

附件包含安装包、应用源码、第三方源码及声明、两种架构的签名更新清单、镜像归档和 SHA-256 校验和。第三方附件体积较大，日常安装只需对应系统与芯片的 ZIP。旧私有附件已备份归档，不再分发。

本工具仅供本机单人使用，不是任天堂官方产品；上游接口、认证和资源服务可能变化。已知限制及安全扫描边界见验收报告和 `BETA_TESTING.md`。
