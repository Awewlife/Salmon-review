# Salmon Review v0.3.8

私有试用版，适用于 Windows Intel/AMD 64 位电脑和 Docker Desktop 的 Linux 容器模式。

## 本次变化

- 掉线局纳入场次列表与图表编号，列表展示原始结算零值，保留真实结束分数。掉线局仍不计入通过率及场均表现。
- 表现图以零刻度的灰色空心圆标出掉线局，原色实线依次经过该节点；分数图在实际分数处显示灰色空心节点。三张分项图及图片导出同步生效。
- 已确认相邻且队友身份连续的掉线局不再打断组队判断，也不增加有效场数。例如“同队 4 场 → 掉线 → 同队 2 场”识别为连续同队 6 场。真正缺场、队友离队或相邻关系不明仍断开。
- 点击总览表现趋势的场次直接进入对应对局，掉线点同样可点击；三张分项图继续通过“查看详细趋势”打开。
- 排班卡片左下显示本期四把武器，窄窗口也显示，悬停可查看名称。
- GitHub 更新权限提交后立即显示“正在校验”，清除旧错误并防止重复提交。

## 已有带更新组件的版本

在“数据与同步 → 版本与更新”连接自己的 GitHub 更新权限，点击“检查更新 → 更新到 0.3.8”。已有 0.3.7 或 0.3.6 私有更新开发版可使用此路径；下载期间可继续查看战绩，安装时会短暂重启。无需导出再导入数据。

仓库保持私有。仓库所有者可使用仅选择本仓库、Contents: Read-only 的细粒度令牌；受邀协作者的配置方式见 UPDATING.md。不要共享维护者凭据。

## 首次安装或从不带更新组件的旧版升级

1. 下载 **SalmonReview-v0.3.8-windows-x64.zip**，完整解压到新文件夹。
2. 启动 Docker Desktop，复制原 `.env`（如果有）。
3. 使用原项目名和端口运行 **Start.cmd**。自定义项目名示例：`./Start.cmd -ProjectName 原项目名`。
4. 启动成功后重新打开网页。沿用原项目和数据卷即可保留战绩及登录状态。

不要删除数据卷或执行 `docker compose down -v`。GitHub 自动生成的 Source code 包不含镜像；完整安装包无需自行 build。任天堂凭据过期仍需重新连接。
