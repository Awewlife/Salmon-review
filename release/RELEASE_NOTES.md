# Salmon Review v0.4.1

本版新增历史表现对比与打工数据速查，并改进同步等待和界面说明。

## 本版变化

- **历史表现**：点击左下角头像，以本机已保存的有效结算查看五维图、场均表和日期覆盖。
- **近期对比**：比较最近 100 场与全部历史，或与紧邻之前的 100 场。对照使用紫色虚线；支持指数／场均表切换，样本不足时显示实际场数。
- **打工数据**：离线查询鲑鱼血量、打工武器伤害、危险度和交蛋配额；支持搜索、分类和怪物／武器图标。特殊机制可通过数值旁的小问号查看。
- **同步等待**：请求受限时按实际剩余时间等待，服务明确提供时间时优先遵守；无时间信息时默认一小时。重复点击或重启不会重新累计一小时。
- **导出与语言**：历史与对比图可导出当前范围、图例和表格，五种界面语言同步支持；鱿鱼语仅导出 PNG。整理统计、同步、更新及导出中的说明文字。
- **依赖与许可**：更新 undici、body-parser 和 qs 的安全修复版本；补齐打工数据来源和许可材料，安装包与第三方附件均包含相应声明。

## 安装与升级

已有 **0.4.0** 的用户，可在本版正式发布后打开 **数据与同步 → 版本与更新**，点击检查并安装。战绩、设置和登录状态沿用原数据卷；登录凭据本身过期时仍需重新连接。

首次安装选择相应附件并完整解压：

| 系统 | 安装包 | 启动方式 |
| --- | --- | --- |
| Windows x64 | `SalmonReview-v0.4.1-windows-x64.zip` | `Start.cmd` |
| Intel Mac | `SalmonReview-v0.4.1-macos-x64.zip` | `Start.command` |
| Apple Silicon Mac | `SalmonReview-v0.4.1-macos-arm64.zip` | `Start.command` |

需要 Docker Desktop 的 Linux 容器模式。手动升级和旧私有版迁移须沿用原项目名与数据卷，不要删除原实例。

> **Mac 安装包尚未经过实机测试。** 脚本与 Linux 容器测试不能替代真实 Mac 上的首次安装、登录同步和图表导出验收。

**与 NSO 一样，单次同步只能获取最近约 50 场打工记录，无法获取 NSO 已经查不到的数据。** 更长的本地历史依靠持续同步归档；官方生涯纪录与本地历史统计独立展示。

日常安装只需对应系统的 ZIP。附件另含两种架构镜像、签名更新清单、应用源码、第三方源码与许可、SHA-256 校验和及构建验收报告。社区速查资料可能滞后于游戏更新；游戏图片与名称的权利仍归原权利人。
