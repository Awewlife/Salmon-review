# Salmon Review v0.3.9

私有试用版，适用于 Windows Intel/AMD 64 位电脑和 Docker Desktop 的 Linux 容器模式。

## 本次变化

- 趋势详情新增「数量 / 占比」切换，可显示团队合计及可选的 25% 参考线。数量模式参考线按每场四人合计除以 4；占比模式支持自动缩放或固定 0–100%。有效全零场次显示 0%，掉线与缺失数据不计入占比。
- 三张趋势图同步定位场次、突出玩家；人名靠近各自折线末端避让，拥挤时悬停查看。PNG / SVG 导出同步保留所选模式和参考线。
- 分数图支持跨段位连续刻度：升段向上、降段向下，保留真实段位和分数；纯传说仍按原始分数自动缩放。
- 修复跨段位图在宽屏中异常放大。表现图与分数图统一宽度和节点横向位置，宽屏居中并保留左右留白。
- 「数据与同步」新增一键诊断：显示本地服务、数据库、读取、同步和更新状态及耗时，支持取消、重试和导出部分结果。诊断 JSON 不含令牌、昵称、原始战绩、路径或原始日志，不会自动上传。
- 新版更新组件支持在签名核对、下载阶段取消更新；安装开始后不可取消。成功更新后按保留策略清理旧镜像和备份，保留当前版、上一成功版、容器依赖镜像及最近两份校验通过的备份。

## 已安装用户怎么升级

**只升级主程序：** 在「数据与同步 → 版本与更新」使用自己的 GitHub 更新权限，检查并安装 0.3.9。已有带更新组件的版本可使用此路径，战绩和设置沿用原数据卷。

**启用取消更新与新版自动清理：** 网页更新暂不替换 updater 组件，已有用户请下载本版完整安装包，完整解压到新文件夹，复制原 `.env`（如果有），使用原项目名和端口运行 `Start.cmd`。自定义项目名示例：`./Start.cmd -ProjectName 原项目名`。无需导出再导入战绩。

旧备份若缺少校验记录会继续保留。不会执行全局 Docker prune；不要删除数据卷或运行 `docker compose down -v`。任天堂凭据过期仍需重新连接。

## 首次安装

1. 下载 **SalmonReview-v0.3.9-windows-x64.zip** 并完整解压。
2. 启动 Docker Desktop，确认使用 Linux 容器模式。
3. 双击 **Start.cmd**，按提示打开本机网页。

仓库保持私有，下载和网页更新需要账号具有仓库访问权限。使用各自的 GitHub 凭据，不要共享维护者令牌。详细授权步骤见 UPDATING.md。
