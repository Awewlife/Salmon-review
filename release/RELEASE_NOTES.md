# Salmon Review v0.3.5

修复读取战绩过慢、页面在“正在读取”和“读取失败”之间循环的问题。适用于 Windows Intel/AMD 64 位电脑和 Docker Desktop 的 Linux 容器模式。

## 修复内容

旧版每次读取战绩都会重复写入图片地址。记录较多或磁盘较慢时，同步写入会阻塞应用，连状态接口也可能超时；网页超过 30 秒后重试，进一步加重等待。

新版先按图片 ID 去重，只把新增或变化的地址在一个事务中保存。已有索引不变时，读取不再写数据库；重启后也保持这个行为。战绩统计、图片路径和数据库结构不变，仍包含 v0.3.4 的 Docker 镜像校验兼容修复。

## 下载与升级

1. 下载 **SalmonReview-v0.3.5-windows-x64.zip**，完整解压到新文件夹。
2. 关闭旧版 Salmon Review 网页，复制旧 `.env`（如果有）。
3. 默认项目名用户双击新版 **Start.cmd**。自定义项目名用户运行 `./Start.cmd -ProjectName 原项目名`，端口也沿用原设置。
4. 启动成功后重新打开网页。继续使用同名 Docker 数据卷，正常升级无需导出再导入战绩。

不要删除数据卷或执行 `docker compose down -v`。安装包包含预构建镜像，不需要自行 build 或访问 npm / Docker Hub；账号登录和同步仍需联网。凭据本身若已过期，需要按页面提示重新连接。

其他附件：`SalmonReview-v0.3.5-source.zip` 为对应源码，`SalmonReview-v0.3.5-third-party.zip` 为第三方材料，`SHA256SUMS.txt` 为附件校验值。GitHub 自动生成的 Source code 压缩包不含镜像。

## 验证范围

- 本机同一组 199 场模拟记录：修复前每次读取产生 2787 次数据库改动，修复后首次为 1 次、重复读取为 0 次。对应读取时间从约 1.1 秒降到约 22–31 毫秒；这是本机模拟样本，不代表所有电脑或真实归档的性能。
- 回归覆盖重复读取、重启后零写入、原始战绩保持一致、图片地址更新及事务失败回滚。
- 另一台电脑旧版实测读取耗时 47.83 秒，超过网页超时；该电脑升级后的实际耗时仍待用户验收。
