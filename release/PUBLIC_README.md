# Salmon Review

这里是 Salmon Review 的公开发行入口。它是一个本地运行的 Splatoon 3 打工复盘工具，战绩与登录信息保存在玩家自己的电脑上。

## 当前状态

网页一键更新功能正在验证，**本仓库暂未提供公开二进制安装包**。已有的 0.3.5 私有试用包不会因为这个仓库建立而自动获得更新能力。

预定流程：首次下载完整安装包并启动，之后在网页的“版本与更新”查看新版、点击更新。下载期间继续使用原版；安装时保留战绩和设置，并在失败时尝试恢复旧版。

## 为什么暂时没有安装包

现有上游依赖 `splatnet3-types` 的包与仓库尚未找到明确的再分发许可。需要获得适用授权或替换依赖后，再公开包含该依赖的预构建镜像。创建这个发行入口不代表该问题已经解决。

后续 Release 将同时提供安装包、对应应用源码、签名更新清单和第三方许可材料。项目代码采用 AGPL-3.0-or-later，任天堂游戏素材与商标不属于该许可。此项目不是任天堂官方产品。

请勿在此仓库上传任天堂登录链接、凭据、Docker 数据卷或包含凭据的更新备份。
