# Salmon Review

Splatoon 3 打工数据复盘工具。本次提交是静态原型基线，后续版本将增加本地 Docker 服务。

## 预览

用静态文件服务器打开 `dist`，或直接打开 `dist/index.html`。
仓库只包含虚构示例数据，不包含真实玩家战绩、账号凭据或游戏图片。

## 已有功能

排班总览、场次详情、搬蛋/击杀/被救援图表、疑似队友对比、特殊武器剩余提示。
AI 区域为演示，后续本地首版将隐藏。

## 采集脚本

`scripts/collect-data.mjs` 是原型采集适配器，依赖已安装且已登录的 nxapi。
`scripts/build-data.py` 将 nxapi 导出记录转为静态网页快照。
这套开发脚本尚不是面向新用户的安装流程。

项目不隶属于 Nintendo。游戏名称和相关标识属于各自权利人。
